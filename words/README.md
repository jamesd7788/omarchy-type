# Word list

`english.json` is Monkeytype's `english` language file — the 200 most
common English words — vendored from
[monkeytypegame/monkeytype](https://github.com/monkeytypegame/monkeytype)
(`frontend/static/languages/english.json`).

Monkeytype is licensed GPL-3.0, which is why this project is too.
